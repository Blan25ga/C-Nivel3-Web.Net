# 💻 Curso C# Nivel 3: Desarrollos Web con ASP .NET WebForms

¡Bienvenido/a al repositorio de proyectos y ejercicios del **Curso C# Nivel 3** de [Maxi Programa](https://maxiprograma.com)! 

En este nivel damos el salto al desarrollo de aplicaciones web, conectando los conceptos de la Programación Orientada a Objetos (POO) y C# con las tecnologías fundamentales de la web y el framework **.NET**.

---

## 📋 Descripción del Curso

Este curso aborda la construcción de aplicaciones web interactivas utilizando **ASP .NET WebForms**, sirviendo como puente directo entre el desarrollo de escritorio (*WinForms*) y el entorno web. Durante el trayecto se combinan lenguajes de marcado y estilos con lógica en C# e interacción directa con bases de datos relacionales para construir aplicaciones listas para producción.

---

## 🎯 Objetivo del Curso

* Comprender la arquitectura y funcionamiento fundamental de la Web.
* Trabajar con los lenguajes fundamentales del frontend: **HTML5, CSS3, JavaScript y Bootstrap**.
* Desarrollar aplicaciones web con **ASP .NET WebForms**.
* Crear aplicaciones con lógica de negocio completa y persistencia en bases de datos (operaciones CRUD/ABM).

---

## 🧠 Requisitos Previos

Para aprovechar al máximo este contenido, se requieren conocimientos sólidos en:
* Fundamentos de programación y algoritmos.
* **Programación Orientada a Objetos (POO)** en C#.
* Nociones básicas sobre **.NET** e interacción con Bases de Datos (SQL Server).

---

## 📚 Contenido del Programa

El curso se compone de **8 unidades de estudio**:

* **Unidad 1: Introducción a la Web**
  * Arquitectura y ámbito web.
  * Fundamentos de HTML, CSS y JavaScript.

* **Unidad 2: Primer Proyecto ASP .NET**
  * Estructura de proyectos web.
  * Diferencias entre ASPX y HTML.
  * Uso de Master Pages e inclusión de archivos.

* **Unidad 3: Diseño e Integración con Bootstrap**
  * Qué es y cómo implementar Bootstrap.
  * Aplicación e integración con controles de ASP .NET.

* **Unidad 4: Manejo del Estado y Eventos**
  * Eventos del ciclo de vida.
  * Pasaje de parámetros.
  * Manejo de Variables de Sesión (`Session`).
  * Introducción a grillas de datos.

* **Unidad 5: Persistencia de Datos**
  * Manipulación de datos desde Base de Datos.
  * Comparativa: `DataGrid` vs `Foreach + HTML`.
  * Uso del control `Repeater`.
  * Introducción a Procedimientos Almacenados (*Stored Procedures*).

* **Unidad 6: Desarrollos de Web App Completa (ABM)**
  * Alta, Baja y Modificación (ABM) desde la interfaz web contra la Base de Datos.
  * Controles desplegables y formularios.
  * Actualización asíncrona con `Update Panel` (AJAX).

* **Unidad 7: Controles Avanzados y Estrategias**
  * Selección de fechas: `DateTimePicker` y `Calendar`.
  * Tablas interactivas y filtrado de información (`JTable`).

* **Unidad 8: Seguridad, Validaciones e Integraciones**
  * Validaciones del lado del cliente (JS) y del servidor (ASP .NET).
  * Expresiones Regulares (RegEx).
  * Autenticación y manejo de perfiles (Login / Registro).
  * Subida y procesamiento de imágenes.
  * Envío de correos electrónicos desde C#.
